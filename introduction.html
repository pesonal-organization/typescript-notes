Question 2❓

Q: temperary and permanent solution?

✅ Answer

        Temporary solution 
        Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
        and after this 
        tsc --init

        ✅ Fix Option 2 (Permanent for your user account)

If you want to allow script running permanently (safe for development):

Open PowerShell as Administrator

Run:

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned


Then confirm with Y (Yes)

Now try again:

tsc --init


It should work fine now 🎉

Question 7❓

Q: What is Generic type?

✅ Answer

The one property of object that we donot know what type is coming, when we use Generic.
after name of interface we keep 

<>
and inside 
<>
we write 'Type' when in object when we write interface name than we describe type like 
User

💡 Example


       
        interface User<Type> {
    name : string,
    email : string,
    data : Type
}
const User_1 : User<string> = {
    name : 'Ahmed',
    email: 'xyz',
    data : 'testing'
}
console.log(User_1)

Question 15❓

Q: Difference between interface and type?

✅ Answer

we can use same name interface multiple times but we can not use type same name multiple time.
when we use type we give = after type name but in interface donot give any thing after interface name and before { }.
we can declare same name interface again/tripple time double time but in type we can not declare same name type again.

💡 Example


       
        interface

        interface User {

    name : string
}
interface User {
    age : number
}
const user : User = {
    name : 'Aziz',
    age : 22
}
console.log(user)
____________________________________________________________
type 

type User = {
    name : string
}
type User = {
    age : number
}

const user_1 : User = {
    name :'Aziz',
    age : 24
}
console.log(user_1)

Question 15❓

Q: type union in typescript?

✅ Answer

we write type and give it name like Id and save more than one types like string or number
now we can make a variable and it variabe can have number or string because we have described two type by using pipe(|) symbol .

💡 Example


        
          type Id = string | number;
        const data : Id = 324;
        console.log(data)


        type Value = string | number[];
        const data1 : Value = [2,3,4]
        console.log(data1)
