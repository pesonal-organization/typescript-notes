Question 1❓

Q: what is Typescript?

✅ Answer

Typescript is created by microsoft.
Typescript helps us finding errors before running code.
It is just JavaScript with rules(types)
Typescript = JavaScript + Extra safety
Typescript checks our code for mistakes.
Make big project easier to manage
Turns into normal JavaScript so browser can read and run it.
Run type script 

        server run 
        tsc app.ts 
        node app.js

Question 2❓

Q: temperary and permanent solution?

✅ Answer

        Temporary solution 
        Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
        and after this 
        tsc --init

        ✅ Fix Option 2 (Permanent for your user account)

If you want to allow script running permanently (safe for development):

Open PowerShell as Administrator

Run:

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned


Then confirm with Y (Yes)

Now try again:

tsc --init


It should work fine now 🎉

Question 5❓

Q: what is interface?

✅ Answer

interface is a reserved keyword that is used to apply Typescript on object , in interface we tell the type of properties and than we store properties in object.

Question 6❓

Q: what is primitive and non-primitive data types?

✅ Answer

primitive data type means that has single value like string, number or boolean
and non-primitive data type means that stroes multiple values like object and array.
